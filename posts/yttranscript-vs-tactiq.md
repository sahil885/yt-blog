## Tactiq: The Multi-Platform Extension

Tactiq is a Chrome extension that integrates directly into YouTube, Google Meet, and Zoom. It adds a transcript extraction button to the YouTube interface and captures live transcripts during video calls.

**What makes it stand out:**
- Integrated into YouTube's interface — no separate site to visit
- Captures live transcripts from Zoom and Google Meet in real time
- AI summary and action item features (on paid tiers)
- Popular with teams who need call transcription alongside video transcription

**Where it falls short:**
- Requires installing a Chrome extension
- An account is required for full functionality
- Free tier significantly limits transcript export
- Desktop/Chrome only — no mobile support
- Overkill if all you need is YouTube transcripts

## Which Should You Choose?

**Choose YTTranscript if you:**
- Just need YouTube transcripts quickly and cleanly
- Don't want to install browser extensions
- Use a mobile device or non-Chrome browser
- Want to download transcripts as DOCX or PDF for free
- Will be using the transcript with ChatGPT, Notion, or Google Docs

**Choose Tactiq if you:**
- Spend significant time on Zoom or Google Meet and want call transcription alongside YouTube

- Are willing to pay for AI summary and action item features
- Use Chrome exclusively on desktop
